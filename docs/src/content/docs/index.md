---
title: crossrepo
description: Create, sync and remove the same git worktree branch across many sibling repos with one command.
---

crossrepo creates, syncs and removes the same git worktree branch across many sibling repos with one command.

crossrepo is in early development and has no usable release yet. See [Install](install/) for the current state.

The source code is on [GitHub](https://github.com/alexsuprun/crossrepo).
